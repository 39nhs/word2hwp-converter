# 워드 → 한글 변환기 (word2hwp-converter)

Word 문서(.docx)를 한글 문서(.hwp / .hwpx)로 바꿔 주는 Windows용 프로그램입니다.
한컴오피스나 MS Word 가 설치되어 있지 않아도 동작하며, 변환된 문서는 한글에서 글자·표·수식을 그대로 고칠 수 있습니다.

## 웹에서 바로 쓰기

**https://39nhs.github.io/word2hwp-converter/**

설치 없이 브라우저에서 변환합니다. 파일은 서버로 올라가지 않고 브라우저 안에서만 변환됩니다
([Pyodide](https://pyodide.org) 로 `word2hwp_core.py` 를 브라우저에서 실행).

## Windows 프로그램 사용법

1. 이 저장소를 내려받아 압축을 풉니다.
2. `워드한글변환기_실행.bat` 을 더블클릭합니다. (처음 한 번은 필요한 구성요소를 자동 설치)
3. 창에 Word 파일을 끌어다 놓거나 "파일 고르기" / "폴더 통째로 변환" 을 누릅니다.
4. 원본과 같은 폴더에 같은 이름의 `.hwp` 파일이 생깁니다. (원본은 그대로)

자세한 내용은 [사용법.txt](사용법.txt) 를 보세요.

## 필요한 것

- Windows 10/11
- Python 3.10 이상 (설치할 때 "Add python.exe to PATH" 체크)
- 인터넷 (처음 실행할 때 `requirements.txt` 의 패키지 설치)

## 옮겨지는 것

- 글꼴·크기·굵게/기울임/밑줄·색·형광펜·위/아래 첨자
- 문단 정렬·들여쓰기/내어쓰기·줄 간격(글꼴별 보정)·문단 간격·탭·쪽 나누기
- 표: 셀 병합, 배경색, 테두리 종류, 열 너비, 행 높이(실제 글꼴 너비로 계산), 셀 여백, 세로 정렬,
  표 안의 표, 쪽 경계에서 행 단위로 나뉨, 제목 줄 반복
- 그림(본문·표·머리말/꼬리말), 수식(한글 수식으로), 각주/미주, 글상자, 번호 목록, 다단
- 용지·여백·방향·구역, 쪽 번호(로마 숫자/다시 시작), "쪽 X / 전체 Y"
- 예전 .doc 는 LibreOffice 가 있으면 자동 변환, 손상/암호/빈 파일은 이유를 알려 주고 건너뜀

한컴오피스(한글)가 설치된 PC 에서는 한글 프로그램으로 직접 변환합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `word2hwp_core.py` | 변환 엔진 (명령줄에서 `python word2hwp_core.py 파일.docx` 로도 사용 가능) |
| `word2hwp_gui.pyw` | 끌어다 놓기 창 |
| `워드한글변환기_실행.bat` | 실행 파일 (구성요소 자동 설치) |
| `requirements.txt` | 필요한 파이썬 패키지 |

## 알려진 한계

- Word 와 한글의 글자 배치 계산이 달라서 줄이 바뀌는 위치·쪽 수가 조금 다를 수 있습니다.
- 차트는 `[차트]` 표시로, SmartArt 는 글자만 옮겨집니다. 떠 있는 그림은 글 줄 안에 놓입니다.
